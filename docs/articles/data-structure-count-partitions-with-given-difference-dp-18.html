Count Partitions with Given Difference (DP - 18)

Archived from https://takeuforward.org/data-structure/count-partitions-with-given-difference-dp-18/

Problem Statement : Given an array with N positive integers and an integer D, count the number of ways we can partition the given array into two subsets, S1 and S2 such that S1 - S2 = D and S1 is always greater than or equal to S2.

Examples 
Input: arr = [1, 1, 2, 3], diff = 1
Output: 3
Explanation: The subsets are [1, 2] and [1, 3], [1, 3] and [1, 2], [1, 1, 2] and [3]. 


Input:  arr = [1, 2, 3, 4], diff = 2
Output: 2
Explanation: The subsets are [1, 3] and [2, 4], [1, 2, 3] and [4].

Approach
Algorithm

We need to split the array into two groups (partitions) such that the difference between their sums is equal to a given number d.

Let the first group have sum = S1 and the second group have sum = S2.

  • We know S1 - S2 = d
  • We also know S1 + S2 = totalSum

If we add both equations, we get 2 * S1 = d + totalSum.

  • So, S1 = (d + totalSum) / 2
  • This means the problem is now reduced to counting subsets of the array whose sum is (d + totalSum)/2

There are some conditions to check before solving:

  • If (d + totalSum) is odd, then division by 2 is not possible, thus, there is no valid partitions
  • If d is greater than totalSum, then it is also impossible, thus, there is no valid partitions

Now the task becomes similar to the problem Count Subsets with Sum K.

  • The required sum target = (d + totalSum) / 2
  • So the new question is: How many subsets of the array have sum equal to target?

We already know how to count subsets with a given sum using Dynamic Programming. So we just apply that solution here with target.

Code 
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    // Function to count partitions with given difference
    int countPartitions(vector<int>& arr, int d) {
        // Calculate total sum of array
        int totalSum = accumulate(arr.begin(), arr.end(), 0);

        // Check if solution is possible
        if ((totalSum + d) % 2 != 0 || d > totalSum) return 0;

        // Calculate target sum
        int K = (totalSum + d) / 2;

        // Create dp array of size K+1
        vector<int> dp(K + 1, 0);

        // Base case: empty set makes sum 0
        dp[0] = 1;

        // If first element <= K, mark it
        if (arr[0] <= K) dp[arr[0]] += 1;

        // Process remaining elements
        for (int i = 1; i < arr.size(); i++) {
            vector<int> curr(K + 1, 0);
            curr[0] = 1;

            for (int t = 0; t <= K; t++) {
                int notTake = dp[t];
                int take = 0;
                if (arr[i] <= t) {
                    take = dp[t - arr[i]];
                }
                curr[t] = take + notTake;
            }
            dp = curr;
        }
        return dp[K];
    }
};

class Solution {
    // Function to count partitions with given difference
    countPartitions(arr, d) {
        // Calculate total sum of array
        let totalSum = arr.reduce((a, b) => a + b, 0);

        // Check if solution is possible
        if ((totalSum + d) % 2 !== 0 || d > totalSum) return 0;

        // Calculate target sum
        let K = (totalSum + d) / 2;

        // Create dp array of size K+1
        let dp = new Array(K + 1).fill(0);
        dp[0] = 1;

        // If first element <= K, mark it
        if (arr[0] <= K) dp[arr[0]] += 1;

        // Process remaining elements
        for (let i = 1; i < arr.length; i++) {
            let curr = new Array(K + 1).fill(0);
            curr[0] = 1;

            for (let t = 0; t <= K; t++) {
                let notTake = dp[t];
                let take = 0;
                if (arr[i] <= t) {
                    take = dp[t - arr[i]];
                }
                curr[t] = take + notTake;
            }
            dp = curr;
        }

        return dp[K];
    }
}
