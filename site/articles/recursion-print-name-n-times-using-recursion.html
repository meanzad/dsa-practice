Print Name N times using Recursion

Archived from https://takeuforward.org/recursion/print-name-n-times-using-recursion/

Problem Description: Given an integer N, write a program to print your name N times.

Examples 
Input: N = 3
Output: Ashish Ashish Ashish 
Explanation: Name is printed 3 times.


Input: N = 1
Output: Ashish 
Explanation: Name is printed once.

Disclaimer: It's highly recommend trying to solve it before looking at the solution.

Approach
Algorithm
To print your name N times using recursion, the approach involves defining a recursive function that takes the current count as a parameter. The function checks if the count has reached N, if it has, the recursion terminates. Otherwise, it prints the name once and recursively calls itself, incrementing the count by one. This way, the name gets printed exactly N times as the recursion progresses. The key is to use the count to keep track of how many times the name has been printed so far and stop once it reaches N.

Code 
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    // Recursive function to print name count times
    void printName(string name, int count, int N) {
        // Base case: if count equals N, stop recursion
        if (count == N)
            return;

        // Print the name
        cout << name << "\n";

        // Recursive call with incremented count
        printName(name, count + 1, N);
    }
};

int main() {
    Solution sol;
    int N = 5;
    string name = "Ashish";

    sol.printName(name, 0, N);

    return 0;
}
